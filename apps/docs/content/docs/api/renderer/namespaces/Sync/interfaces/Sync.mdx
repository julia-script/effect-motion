# Interface: Sync

Defined in: [packages/renderer/src/Sync.ts:252](https://github.com/julia-script/effect-motion/blob/main/packages/renderer/src/Sync.ts#L252)

The retained scene state: the world and HUD tiers, their cameras, the
text and image actors, live sub-compositions, and the object diff map.

## Remarks

Mostly data — the API is the sibling functions ([syncFrame](../functions/syncFrame.mdx),
[whenReady](../functions/whenReady.mdx), [resolveResources](../variables/resolveResources.mdx), [dispose](../variables/dispose.mdx)).

Content lives in one of two tiers. The WORLD scene is drawn through the
frame's camera, so it moves with it; the HUD scene is drawn through an
identity camera, above everything, so it stays fixed to the glass.
