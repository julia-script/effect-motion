## Remarks

The toolkit mesh is created lazily on the first [TextMesh.setLayout](../interfaces/TextMesh.mdx#setlayout)
— its constructor requires a layout, and a text entity has none until its
first layout resolves. Appearance setters are inert until
[TextMesh.commit](../interfaces/TextMesh.mdx#commit) runs; the entity renderer registers commits with
`ctx.waitFor`, so a frame is never drawn with half-built text.

No z-lift: text over a coplanar backdrop wins by paint order (Sync's
`syncLayers`), like any other layer.
