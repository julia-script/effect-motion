# Function: render()

function render<E, LoaderR>(

Defined in: [packages/export/src/Video.ts:78](https://github.com/julia-script/effect-motion/blob/main/packages/export/src/Video.ts#L78)

Render a scene to a video file at `outPath`.

Fails with [Ffmpeg.EncodeError](../../Ffmpeg/classes/EncodeError.mdx) on odd output dimensions (invalid for
`yuv420p`) — before any ffmpeg process is spawned — or on an ffmpeg failure;
a GPU render failure surfaces as `ThreeException`; a failed resource
(font layout, image decode) as `EffectMotionError`.
