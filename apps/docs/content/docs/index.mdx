**effect-motion** is a library for making motion graphics in code. You write a
scene as a program — instantiate shapes, text, and paths, then compose motions
over them — and the library produces an exact sequence of frames you can play
in the browser or export to video.

Three properties define it:

- **Deterministic.** A scene is a pure function of its settings and seed. The
  same scene produces the same frames, every run, on every machine — including
  its randomness, which comes from a seeded `Random` service instead of
  `Math.random()`.
- **Frame-exact.** Animations don't drift: a duration-based motion lands its
  final frame exactly on target, and concurrent animations advance through a
  shared frame barrier, so composition never changes the math.
- **Composed with [Effect](https://effect.website).** Scenes, animators, and
  combinators are Effects. Everything you know about composing Effects —
  piping, forking, scheduling — is how you compose motion.

It renders in 2.5D: flat shapes positioned in 3D space, projected through an
After Effects–style camera. It is deliberately **not** a GUI editor, and not
a runtime UI-animation library — it's for producing *videos* (explainers,
math visualizations, dev content) from code you can review, diff, and
generate.
