## Remarks

The `Font.Font` / `Image.Image` contract: `yield*` the constant in a scene
to get the reference for [play](./play.mdx), and pair it with [layer](../functions/layer.mdx) to
provide the bytes. Declaring or playing a track never needs its bytes to
produce frames; only [duration](../functions/duration.mdx) adds a real requirement.
