---
title: Grid warp
description: A coordinate grid bent through nonlinear functions — watching space itself deform
---

**The idea:** you can't see a function of the plane, but you can see what
it does to a grid. Every grid line is a densely sampled `Path`; one driven
parameter interpolates each sample from its straight position to its warped
one — first a gentle swell, then a swirl that strengthens toward the
center, then back. All the lines morph in lockstep because they share one
`Scene.all`.
