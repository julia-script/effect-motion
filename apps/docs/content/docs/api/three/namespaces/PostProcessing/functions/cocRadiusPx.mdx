# Function: cocRadiusPx()

function cocRadiusPx(

Defined in: [packages/three/src/DepthAwareDof.ts:171](https://github.com/julia-script/effect-motion/blob/main/packages/three/src/DepthAwareDof.ts#L171)

Physical thin-lens CoC radius (px) at view distance d = −viewZ: a lens of
radius `aperture` focused at `focusDistance` images the point as a disc of
world radius aperture · |d − focus| / d on the focus plane, projected by
`pxPerUnit` ([pxPerUnitAtFocus](./pxPerUnitAtFocus.mdx)). Near blur grows without bound as
d → 0; far blur saturates at aperture · pxPerUnit.
